# 字幕查词（SubWord）

在 App 里看 YouTube（手机版网页），点字幕里的词：视频暂停，弹出 AI 给的这个词在这句里的意思（音标、意思、原形、其他意思），可以加入生词本；点别处收起，视频接着播放。不会一下显示整句翻译，要的时候点「翻译整句」。

- 按住字幕里的一个词（震一下、框住这个词、视频暂停），不松手拖到别的词上：框住中间的几个词（可以跨行），抬手一起查。2～4 个词按短语讲意思，超过 4 个词直接翻译。
- 释义开着时点字幕里的另一个词：直接换成查那个词，视频保持暂停；按住拖动也一样能划词；点别处才收起。
- 全屏时单指点画面不会点出控制条（免得点词点偏了拖到进度条），两指同时点一下调出控制条；控制条出来后照常点。双击左右两边照常倒退、快进 10 秒（接着点继续快进），按住照常 2 倍速。
- 控制条亮着时，按在全屏键、进度条、时间这些控件上照常用（小屏时字幕压在它们上面），按在别处的字幕上照常查词。
- 简介、评论等网页文字：长按选中，菜单里第一项「AI 查词」。选中的超过 4 个词时直接翻译。点、长按评论时不再整条泛蓝。
- 生词本：点一条回到视频里查这个词的那一秒；长按删除；右上角「导出」。
- 在 YouTube App 里「分享」→「字幕查词」，可以直接在这里打开那个视频。
- 卡片底部显示「第 N 次查这个词」：查得多的词，说明还没记住。

## 用法

1. 右上角「设置」：填 API Key。默认用 DeepSeek 的 Anthropic 接口（和 iPad 上的 LearningPack 一样），也可以选 OpenAI 兼容接口。点「保存并测试」检查一下。
2. 打开视频，在播放器里打开字幕（CC）。自动生成的英文字幕也可以点。
3. 点字幕里的词。

## 生词导入 iPad

生词本导出的 `下载/SubWord/vocab-*.jsonl`，字段和 LearningPack 的 `PackFormat/import_vocab.sh` 一致：

```sh
adb pull /sdcard/Download/SubWord/vocab-20261014-211335.jsonl /tmp/
cd ~/vscode/Learning && PackFormat/import_vocab.sh /tmp/vocab-20261014-211335.jsonl
```

## 构建与安装

```sh
sh ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

小米手机要先在「开发者选项」里打开「USB 安装」，安装时在手机上确认。

## 代码

纯 Java、不用 AndroidX，和 time-tracker-android 一样的构建配置（AGP 8.13.2、JDK 17）。

| 文件 | 内容 |
|---|---|
| `assets/subword.js` | 注入网页：按下时按坐标算出落在字幕（`.ytp-caption-segment`）的哪个词上（YouTube 不停地重新生成字幕元素，控制层又盖在字幕上，所以不改字幕结构、不看点到的元素）；在 window 捕获阶段截下整个手势，播放器收不到；控制条亮着时按在按钮、进度条上的不截；暂停、叠一个黄框高亮、把词和字幕交给 App；全屏时控制条没出来就截下单指点击，两指点一下给播放器发一次点击调出控制条；截下的单指手势照着发给播放器：按下时发按下（按住 500ms 播放器自己变 2 倍速），抬手、滑动时发取消（播放器不当成点了一下），300ms 内在差不多的地方又按下就给播放器连点两下（双击快进倒退）；按在字幕窗口边上（字幕滚动时会挪几个像素）也先截下，抬手时找最近的词；按住词不动 200ms 开始划词，拖到哪个词框到哪个词（用开始那一刻的字幕算位置），抬手查框住的几个词；后面的触摸事件也在按下时手指下的元素上听（控制层没生成时那是字幕本身，被 YouTube 换掉后事件传不到 window，抬手会丢）；全屏收起释义、接着播放时播放器自己亮出的控制条，先设透明再点一下收起；`__subwordPress()` 释义开着时透明层上的手势转过来，和网页里的手势走同一套（点词、划词）；去掉评论的点按高亮；`__subwordResume()` 接着播放；`__subwordSelection()` 取长按选中的文字（选区已经被清掉时用最近一次选中的） |
| `MainActivity` | WebView、释义小悬浮窗（贴在词的上方，放不下时下方；开着时透明层上的手势转给网页，网页没查词才收起；开始划词时震一下）、全屏播放（退出时清掉横屏留下的挖孔安全区）、长按菜单、返回键 |
| `Ai` | 提示词（改自 LearningPack 的 `VocabAI`）、流式请求、解析「音标 / 意思 / 原形 / 其他」 |
| `VocabDb` | SQLite：生词本 `vocab`（同一个词只记一条）、查词记录 `lookups`；导出 jsonl |
| `VocabActivity`、`SettingsActivity` | 生词本、AI 设置 |

调试版开了 WebView 远程调试：`adb forward tcp:9229 localabstract:webview_devtools_remote_<pid>` 后用 Chrome 的 `chrome://inspect` 或调试协议查看网页。
